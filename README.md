# 刷题宝（Shuati）

一个**纯本地、零依赖**的单文件刷题软件。只需一个 `index.html`，双击即可在浏览器中打开使用，**无需联网、无需服务器**。

## ✨ 功能特性

- 📥 **导入 Excel / CSV 题库**：自动识别题干、选项、答案、题型、解析；支持单选 / 多选 / 判断 / 填空。
- 📚 **多题库管理**：可导入多个题库，首页自由选择；支持删除题库。
- 🎯 **题库练习**：按题型（单选 / 多选 / 判断）分类练习，答错自动显示正确答案与解析。
- 📝 **模拟考试**：随机抽题（单选 50×1 分、多选 20×2 分、判断 10×1 分），每次随机生成。
- 📊 **历史成绩**：记录每次考试时间、得分、得分率，可查看当次做错的题目。
- 🏠 **一键返回首页**：任意界面均可返回首页。

## 🚀 使用方法

1. 双击 `index.html`（或拖入浏览器）打开。
2. 首次使用点「下载模板」获取标准 Excel 模板，按格式填写题目。
3. 点「＋ 导入新题库」选择填好的 `.xlsx / .xls / .csv` 文件。
4. 在首页选择要用的题库，点「题库练习」或「模拟考试」开始。

> 所有数据保存在浏览器 `localStorage` 中，不会上传到任何服务器。

## 📋 Excel 题库格式

模板表头（首行）建议如下，列名含关键字即可被自动识别：

| 列 | 说明 | 示例 |
|----|------|------|
| 题干 | 题目内容 | 下列哪一项是正确的？ |
| 选项A ~ 选项F | 最多 6 个选项 | A. xxx　B. xxx … |
| 答案 | 正确答案 | `D` / `AB` / `正确` |
| 题型（可选） | 单选 / 多选 / 判断 / 填空 | 单选 |
| 解析（可选） | 答案解析 | 因为…… |

**答案填写规则：**
- 单选题：单个字母，如 `D`、`d`、`D.` 皆可。
- 多选题：多个字母连写，如 `AB`、`A,C`、`BD`。
- 判断题：`正确` / `错误`（也支持 `对`/`错`、`√`/`×`、`true`/`false`、`1`/`0`）。
- 数字也支持：`1`→A，`2`→B …… `4`→D。
- 题型列省略时，程序会按答案自动推断题型。

## 🛠 技术说明

- 单文件 `index.html`，SheetJS（XLSX）解析库已内联，**无任何外部依赖**。
- 纯前端实现，数据存于浏览器本地，隐私安全。
